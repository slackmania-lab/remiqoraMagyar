# Példa receptek / Example recipes

Kész generálási receptek (`.remiqora.json`): töltsd be őket a YuE2-form **📥** gombjával, és ugyanaz a szám legenerálódik (seed elöl a fájlnévben).

Ready-made generation recipes: load them with the **📥** button on the YuE2 form to regenerate the same track (seed leads the filename).

- `720725_...` — Dunai éjféli blues (magyar szöveg, 7 versszak, COT full, q8_0)
- `2095070973_...` — Hungarian Delta blues (COT full, q8_0)

Megjegyzés: a GPU-s mintavételezés nem bit-pontos gépek között — ugyanaz a zene születik, apró renderelési eltérések lehetnek.
Note: GPU sampling is near-deterministic, not bit-exact across machines.
